# AutoCAD_2D_Drawing_Practice
# Overview
This repository contains a collection of 2D AutoCAD drawings created for CAD drafting and geometric construction practice.
The drawings cover mechanical profiles, geometric constructions, dimensional drafting, circular and elliptical features, symmetry, construction lines, and hatching.
# Main Topics Covered
- 2D geometric construction
- Mechanical component profiles
- Symmetrical part design
- Circle and arc construction
- Ellipse construction
- Polygon construction
- Construction and reference lines
- Dimensioning
- Radius and diameter notation
- Hatch patterns
- Coordinate-based drafting

# 1. Symmetrical Circular Flange Profile
File: `Drawing1.dwg`
# Main Features
- Central circular feature
- Four outer circular features
- Symmetrical geometry
- Circular and curved profile construction
- Repeated features around the center
# Process
1. Establish the main center and reference geometry.
2. Create the central circular feature.
3. Construct the outer circular features.
4. Develop the connecting curved profile.
5. Use symmetry and repeated geometry to complete the part.
6. Trim unnecessary construction elements.
# 2. Symmetrical Mounting Plate Profile
File: `Drawing2.dwg`
# Main Features
- Two main circular sections
- Multiple circular holes
- Symmetrical arrangement
- Connecting outer profile
- Construction/reference geometry
# Process
1. Create the horizontal and vertical center references.
2. Draw the main circular sections.
3. Create the required holes using concentric circles.
4. Construct the connecting outer boundaries.
5. Apply symmetry to maintain equal spacing.
6. Trim and clean the final profile.
# 3. Wrench / Spanner Profile
**File:** `Drawing3.dwg`
# Main Features
- Open-ended mechanical profile
- Two circular end regions
- Hexagonal internal profiles
- Central connecting section
- Slot-like central opening
- Dimensions including 140, 70, R30 and R20
# Process
1. Draw the two main circular end regions.
2. Construct the internal polygonal profiles.
3. Create the connecting section between the two ends.
4. Draw the central slot.
5. Apply the required radii and dimensions.
6. Trim and join the geometry to form the final wrench profile.
# 5. Coordinate-Based Geometric Construction
File: `Drawing5.dwg`
# Main Features
- X and Y reference axes
- Multiple construction points
- Profiles labelled a, b, c and d
- Vertical dimensions of 40 and 30
- Coordinate-based construction
# Process
1. Establish the X and Y reference axes.
2. Mark the required distances along the axes.
3. Create construction points using the given dimensions.
4. Draw the required vertical and horizontal lines.
5. Connect the reference points to form the profiles.
6. Verify the dimensions and alignment.
# 6. Dimensioned Mechanical Plate Profile
File: `Drawing6.dwg`
# Main Features
- Complex mechanical profile
- Multiple circular holes
- Arcs and tangent curves
- Hatch pattern
- Radius and diameter dimensions
- Overall dimensional references
# Process
1. Establish the main reference geometry.
2. Draw the primary circular and curved features.
3. Construct the internal holes and circular sections.
4. Apply tangent arcs and required radii.
5. Add the required dimensions.
6. Apply hatch to the required closed region.
7. Trim and clean the final mechanical profile.
# 7. Ellipse Construction – 110 × 70
File: `Drawing11.dwg`
# Main Features
- Elliptical construction
- Construction/reference lines
- Approximate overall dimensions of 110 × 70
- Multiple construction points
- Geometric division method
# Process
1. Create the construction rectangle.
2. Set the major and minor dimensions.
3. Mark the required construction points.
4. Draw reference lines between the points.
5. Generate the ellipse using the construction geometry.
6. Remove unnecessary construction elements.
